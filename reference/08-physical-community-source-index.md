# Physical community / live-event source index

## Purpose

This matrix records what the current physical-community sources actually establish. It exists so later files can distinguish:

- a real event from an event remembered later;
- a gallery upload date from an event date;
- a named person in a caption from speculation about their role;
- a fan-maintained event summary from primary audio or a physical ticket.

# M. Research rules emerging from this source set

1. **A restored gallery's displayed date is not necessarily the historical event date.**
2. A filename/caption can establish a handle's physical presence without establishing private relationships.
3. A fan-maintained Wikipedia-style event list is a retrieval map, not final proof.
4. Current participant archive sites such as The Hideout are strong for their own show history but still benefit from original tape verification.
5. Physical artifacts such as tickets can settle basic facts more cleanly than decades of oral memory.
6. Modern search results must not be used to deanonymize old handles through people-search/data-broker services.
7. Very small details—who photographed an event, who corrected a gallery caption, who sang which karaoke song—often reveal **how the community actually operated**.

This matrix should be extended whenever a new party, venue, ticket, photograph, show tape, flyer, or participant is recovered.
