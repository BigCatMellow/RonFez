# Governing rule from this source set

These cases repeatedly show why **source type must remain visible**:

- A ticket/file title can settle a date cleanly.
- A publisher summary can date a party without telling us what happened inside it.
- A participant can remember extraordinary details but be uncertain about the year.
- A later fan can accurately preserve the texture of an event while misremembering chronology.
- A phrase such as “second annual” can prove a predecessor existed even when the predecessor's file has not yet been found.

The archive should preserve all of those layers rather than forcing them into one confidence level.
