# Ron & Fez Poker Tournament — 2003

## Classification

**WJFK/Fairfax listener event / game-show parody night / physical challenge / music/performance event / civilian-cast convergence**

## Date and venue status

The event is consistently identified in surviving R&F historical summaries as **Ron and Fez Poker Tournament (2003)**.

Exact calendar date and venue have not yet been recovered from a primary event listing.

The surviving historical summary says the event included:

- a poker tournament;
- **The Honeymooner Game**;
- **The Gong Show**;
- **The Mating Game**;
- **J Dubs and Crazy Jen's Fire and Ice Challenge**;

## Why this event matters

The event title says “Poker Tournament,” but the remembered program is much broader. Poker appears to be the shell around a miniature variety show built from:

- dating/game-show parody;
- performance;
- physical pain/endurance;
- recognizable civilian personalities;
- alcohol-driven unpredictability.

That is a recurring R&F event pattern: the advertised activity creates a room, then **the people in the room become the content**.
