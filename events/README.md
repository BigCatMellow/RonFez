## Case-file standard

Each event file should eventually include exact date/time; venue/address; whether live/taped/remote/fan-organized/off-air; lead-up broadcasts; full staff and civilian rosters; event timeline; music/entrance cues; results; capacity/security issues; work/shoot elements; photographs/video/audio; original RFNet/Wackbag/Paltalk discussion; next-show aftermath; participant retrospectives; anomalies; evidence grades; and open questions.

## Archive-date warning

Many restored RonFez.net gallery pages show **upload/restoration dates that are not necessarily event dates**. Event chronology requires a second anchor such as a ticket, contemporary thread, broadcast, original file metadata or independent listing.
