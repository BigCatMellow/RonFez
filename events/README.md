## Case-file standard

Each event file should eventually include:

1. exact date/time;
2. exact venue/address where publicly documented;
3. whether live, taped, remote, fan-organized or off-air social;
4. lead-up broadcasts;
5. full participant roster;
6. civilian/fan roster where recoverable;
7. ordered event timeline;
8. music/entrance cues;
9. contest/fight results;
10. capacity/security/police/fire-marshal issues;
11. work/shoot elements;
12. photographs/video/audio;
13. original RFNet/Wackbag/Paltalk discussion;
14. next-day/next-show aftermath;
15. later participant retrospectives;
16. important tiny details and anomalies;
17. evidence grades;
18. open questions.

## Archive-date warning

Many restored RonFez.net gallery pages show **2007 upload/restoration dates for events that clearly occurred years earlier**. Therefore:

> **Gallery date is not automatically event date.**

Event chronology requires a second anchor such as a ticket, contemporary thread, broadcast, original file metadata, or independent event listing.

## Governing rule

No event should be summarized as only “they did a live show” when the surviving material supports a full social map. Equally, no missing detail should be invented merely to make the history tidy.
