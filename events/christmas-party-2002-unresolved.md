# Christmas Party 2002 — unresolved event dossier

## Classification

**Early RFNet/community event directly evidenced by a restored gallery category; relationship to `CyberSoldier Holiday Party Pics 2002` unresolved**

## Direct gallery evidence

The restored RonFez.net Photo Gallery contains a surviving category breadcrumb:

> `Home » Main » Events » Christmas Party 2002`

One indexed image in that category is titled:

> **Chris the Cop**

Direct page:
- https://www.ronfez.net/gallery/showphoto.php/photo/527/ppuser/21562

The page currently shows:

- gallery uploader/curator: **mikeyboy**;
- displayed upload date: **May 18, 2007**;
- keyword: `Chris Cop`;
- a later 2007 comment by Don Stugots.

The 2007 gallery date should be treated as restoration/migration metadata, not as the original party date. The category title itself explicitly supplies **2002**.

## What this establishes

At minimum:

1. RFNet's restored gallery preserved a discrete event category called **Christmas Party 2002**;
2. the category contains at least one photograph identified as **Chris the Cop**;
3. Mikeyboy was involved in the later gallery migration/curation;
4. a 2002 physical-community Christmas event was important enough to be retained as its own gallery category.

## Relationship to `CyberSoldier Holiday Party Pics 2002`

Separately, the restored File Library's global `Most Popular Files` block contains:

> **CyberSoldier Holiday Party Pics 2002**

with roughly 10,000+ accumulated downloads.

That creates an obvious hypothesis:

> `Christmas Party 2002` gallery category and `CyberSoldier Holiday Party Pics 2002` may document the same event.

But this is **not yet proven**.

Possible models include:

1. CyberSoldier hosted the event represented by the gallery category;
2. CyberSoldier photographed or packaged pictures from a broader RFNet Christmas party;
3. the File Library item and gallery category were separate 2002 holiday gatherings;
4. `CyberSoldier Holiday Party Pics 2002` is a photo packet later imported into the generic `Christmas Party 2002` category without preserving its original title.

Do not merge the two records until a direct bridge appears.

## Current unknowns

- exact calendar date;
- venue/address;
- whether the event was official, staff-organized, or fan-organized;
- CyberSoldier's role;
- whether Ron, Fez or WNEW staff attended;
- attendee roster beyond the image titled `Chris the Cop`;
- original photographer;
- original uploader;
- whether Mikeyboy migrated an older photo set intact or reconstructed it later;
- whether the File Library's CyberSoldier packet contains the same images as this gallery category.

This is the first concrete structural lead behind the previously opaque **CyberSoldier Holiday Party Pics 2002** title. We still cannot say that CyberSoldier hosted the restored `Christmas Party 2002` gallery event, but we now know that RFNet independently preserved a named 2002 Christmas-party category. The investigation has moved from a single mysterious download title to a testable **file-library ↔ gallery crosswalk**.
